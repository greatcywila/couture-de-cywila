# Images Folder

This folder should contain your project images. Here's what you need:

## Required Images

### 1. `about.jpg` (Recommended: 1200x600px or 1200x800px)
- Used in the About section
- Shows tailoring details, craftsmanship, or products
- Aspect ratio: Landscape (16:9 or 4:3)

### 2. `hero.jpg` (Optional - Currently using gradient)
- Background for hero section
- Recommended: 1920x1080px or larger
- Should complement the luxury aesthetic

### 3. `cta.jpg` (Optional - Currently using gradient)
- Background for Call-to-Action section
- Recommended: 1920x800px or larger
- Should be visually striking

## Image Optimization Tips

1. **File Format**
   - Use JPG for photographs
   - Use PNG for graphics with transparency
   - Consider WebP for modern browsers

2. **File Size**
   - Keep images under 200KB each
   - Use image compression tools:
     - TinyPNG.com
     - Compressor.io
     - ImageOptim (Mac)

3. **Dimensions**
   - Keep aspect ratios consistent
   - Use responsive image sizes
   - 1200px width is ideal for web

4. **Quality**
   - Maintain professional quality
   - Use high-resolution originals
   - Test on different devices

## Adding Images to Website

1. Save your images in this folder with correct names
2. Images are referenced in `index.html` as:
   ```html
   <img src="images/about.jpg" alt="description">
   ```

3. To verify images load correctly:
   - Run local server
   - Check browser console for 404 errors
   - Ensure filenames match exactly (case-sensitive)
